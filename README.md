# 📚 Sistema de Inventario para Librería

Aplicación de escritorio desarrollada en **Java 17** con **MySQL**, diseñada para gestionar el inventario de una librería. 
Permite registrar, actualizar, eliminar productos, controlar stock y generar reportes básicos.

## ✅ Características principales

- Gestión de productos (CRUD)
- Registro de entradas y salidas de stock
- Reporte básico de inventario disponible
- Endpoints disponibles para el frontend
- Persistencia de datos en MySQL
